# Source Integrity Workbench

Turn claims and citations into a reviewable source-integrity ledger, verification queue, and release packet.

**Live:** https://provenance-verify.vercel.app

## Repository contents

`index.html`, `privacy.html`, `robots.txt`, `terms.html`, `vercel.json`

## Local development

Static site. No build step — open `index.html`, or serve the directory with any static file server.

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
